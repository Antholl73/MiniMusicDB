AYUDA PARA QUE USEN GITHUB

ver estado -> git status

ver ramas -> git branch

cambiar de rama -> git checkout nombre (nombre = main u otra rama)

ver historial -> git log --oneline

Otros comandos utiles:

git fetch : sincroniza el historial del repo con el local, usalo antes de hacer un git status

git add .	            ---> agarra todos tus cambios del git status para "staging"

git add "nombre de archivo" ---> agarra solo un cambio de algun archivo que quieras para el "staging"

git commit -m "texto descriptivo" ---> agarra lo que este en tu "staging" y lo vuelve un commit

git push origin main ---> manda tus commits que hayas generado hacia el origen, el repo web
